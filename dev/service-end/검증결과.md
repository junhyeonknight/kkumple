## 확인 범위의 한계

- 운영용 점검기는 이 PC에 설치하지 않았습니다. 각 배포 PC에서 동의하고 설치해야 자동 점검이 시작됩니다.
- 실제 꿈플 본체 설치 EXE가 없어 본체 설치부터 이어지는 전체 설치는 검증하지 않았습니다. 선택 연동 코드는 제공했습니다.
- 코드 서명은 수행하지 않았습니다.
- 검증한 도면 보존은 지정 보호 확장자와 번들 밖 경로에 해당합니다. 임의의 개인 자료가 번들 안에 있는지 식별하는 기능은 없습니다.
- Windows 사용자 계정·권한·보안 정책과 AutoCAD 파일 잠금 상태가 다른 PC에서는 설치나 정리가 실패할 수 있습니다. 실패를 성공으로 기록하지 않고 로그/종료코드를 남깁니다.
- 실행 코드와 경로 검사는 고정된 파일 시스템 상태에서 검증했습니다. 같은 계정의 다른 프로세스가 검사와 삭제 사이에 파일 시스템을 악의적으로 바꾸는 상황에 대한 완전한 격리를 보장하지 않습니다.

## 소스 변경 요점

1. 사용자 SID가 붙는 독립 예약 작업과 고정 설치 위치, 설치·제거·재설치 흐름을 추가했습니다.
2. 등록된 작업 XML의 SID·설명·실행 경로가 일치해야 갱신/제거합니다. 한글 계정의 표시 이름을 SID로 오인하지 않습니다.
3. 정리 성공 시에만 예약 작업을 해제합니다. 잠긴 파일·거부된 연결 폴더가 있으면 표식을 보존하고 재시도합니다.
4. 재귀 전체 열거 대신 하위 항목을 하나씩 검사하고, 경로의 조상에 있는 연결점도 거부합니다.
5. 비차단 종료 안내는 별도 프로세스로 표시하여 정리 프로세스 종료와 함께 사라지지 않게 했습니다.
6. 동의 기록 실패·본체 설치 실패를 설치 성공으로 처리하지 않습니다. 동의 기록은 관리자 권한이 필요 없는 사용자 폴더에 저장합니다.
7. 배포 설정은 `DryRun=false`, 만료일 비활성, 지정 번들과 정확한 소유자 표식으로 고정했습니다. 점검기/로그의 자동 자기 삭제는 해제했습니다.
