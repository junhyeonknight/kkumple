# 꿈플 원격 서비스 종료 — Codex 작업 완료

작성일: 2026-11-17

## 완료

- 사용자별 고정 위치에 에이전트·설정 복사, 매일 09시 예약 작업 등록.
- 더블클릭 설치/제거 스크립트와 설치 전 체크박스 동의 창 연결.
- 실제 배포 설정 `DryRun=false` 반영. 운영용 예약 작업은 이 PC에 설치하지 않음.
- 한글·공백 경로 및 한글 계정 처리, 자기 소유 예약 작업만 갱신/제거.
- 삭제 실패 시 표식·예약 작업 보존 및 재시도, 연결 폴더 차단, 도면 보호.
- EXE 2개 재빌드, 86개 검증 통과, 테스트 예약 작업 모두 제거.
- 공개 상태 파일의 정상 신호(`ended:false`)와 전자서명 확인. GitHub 파일은 변경하지 않음.

## 배포

아래 프로젝트 경로는 바탕화면의 원래 `꿈플-원격스위치` 폴더를 기준으로 한다.

`service-end/배포/자동점검-설치.cmd` 또는 `꿈플-설치.exe`를 사용자 PC에서 실행하여 동의하고 설치한다. 폴더 전체를 전달한다. 설치 위치는 `%LOCALAPPDATA%\Kkumple\ServiceEndAgent`, 예약 작업은 `KkumpleServiceEnd-<사용자 SID>`.

`자동점검-제거.cmd`는 점검기/전용 작업을 제거한다. 꿈플 본체, 도면, 동의 기록과 로그는 남긴다. 자세한 사용법과 제한은 `service-end/README.md`, `검증결과.md`를 참조한다.

## 선택 사항

- 꿈플 본체 설치파일이 제공되면 `consent-config.json`의 `InstallerExe`로 연결할 수 있다. 본체 설치 EXE가 없어 해당 전체 흐름은 미검증이다.
- EXE 코드 서명은 인증서가 없어 미수행.
- 조회 시각은 기본 매일 09시. 로그아웃·PC 종료 중에는 실행되지 않으며 놓친 예약은 사용 가능 시 지연 실행될 수 있다.

## 운영 자료

기존 `service-end/operator/`의 개인키·정상/종료 신호는 그대로 보존했다. 개인키는 읽거나 수정하지 않았으며 배포본에 포함하지 않았다. 실제로 지원 종료를 결정할 때만 운영자가 GitHub의 `status.json`을 기존 서명된 종료 신호로 교체한다.

AutoCAD가 사용 중인 DLL은 잠금 때문에 정리가 지연될 수 있다. AutoCAD를 종료한 뒤 다음 예약 점검에서 재시도한다. 점검기는 AutoCAD를 강제로 종료하지 않는다.
