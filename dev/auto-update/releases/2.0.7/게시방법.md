# 꿈플 자동 업데이트 2.0.7 게시 방법

파일 위치: `E:\꿈플-원격스위치\auto-update\releases\2.0.7\signed`

**순서를 꼭 지켜 주세요. ZIP을 먼저 올리고, update.json은 마지막에 교체합니다.** 순서가 바뀌면 사용자 PC가 아직 없는 ZIP을 받으려다 실패합니다.

## 1. 릴리스 만들기

1. https://github.com/junhyeonknight/kkumple/releases/new 를 엽니다.
2. 태그: `bundle-v2.0.7` 입력 → "Create new tag" 선택 (대상 브랜치: main)
3. 제목: `꿈플 자동 업데이트 2.0.7`
4. 본문(아래를 그대로 붙여넣기):

```
기존 CAD 명령 별칭(L, CO, TR 등)을 바로 입력하면 '알 수 없는 명령'이 나오고 2~3초 뒤에야 인식되던 문제를 고쳤습니다. 사용자 Support 폴더가 지원 파일 경로에서 빠져 acad.pgp를 읽지 못하던 경우, CAD를 시작할 때 자동으로 경로를 복구하고 명령 별칭을 다시 불러옵니다. 경로가 정상인 PC에서는 아무것도 바꾸지 않습니다.

함께 포함: 꿈플 관리 화면에 설치 도우미 버전과 설치된 꿈플 버전을 각각 표시하고, 자동 업데이트가 끝나면 패치노트를 보여 줍니다.
```

5. 아래 ZIP 4개를 첨부 영역으로 끌어다 놓습니다.
   - `kkumple-2.0.7-2010.zip`
   - `kkumple-2.0.7-2013.zip`
   - `kkumple-2.0.7-2015.zip`
   - `kkumple-2.0.7-2025.zip`
6. 업로드가 모두 끝나면 **Publish release**를 누릅니다. ("Set as the latest release" 체크 유지)

## 2. update.json 교체

1. https://github.com/junhyeonknight/kkumple/edit/main/update.json 을 엽니다.
2. 편집 창 내용을 전부 지우고(Ctrl+A → Delete), `signed\update.json` 내용을 그대로 붙여넣습니다. 한 줄짜리 JSON이며, 줄바꿈이나 공백을 바꾸면 서명이 깨집니다.
3. **Commit changes...** → 메시지 `Publish signed Kkumple 2.0.7 automatic update` → main에 직접 커밋합니다.

## 3. 확인

- https://raw.githubusercontent.com/junhyeonknight/kkumple/main/update.json 을 열어 `"version":"2.0.7"`이 보이면 완료입니다. 반영까지 몇 분 걸릴 수 있습니다.
- 이후 CAD를 다시 시작하면 자동으로 2.0.7이 설치됩니다. 패치노트 창이 뜨고, L·CO·TR을 바로 입력해도 실행되면 정상입니다.
