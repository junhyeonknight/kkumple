- 실제 GUI AutoCAD 시작/종료 및 원래 설치 프로그램과의 전체 회귀: 사용자 작업 중인 CAD를 조작하지 않았습니다. 별도 Core Console은 라이선스 오류로 종료되어 실제 로드 검증을 완료하지 못했습니다.
