# 꿈플 AutoCAD 2008/2009 연결기 (시험판 0.2)

## 진단 보고서 자동 전송 (0.2)

- 연결기를 켤 때, 설치·제거 직후, 오류가 날 때, CAD가 꿈플을 불러올 때 진단 보고서가 자동으로 개발자에게 전송됩니다.
- 내용: PC·Windows·.NET 정보, 설치된 AutoCAD/AutoCAD LT 제품과 acad.exe 버전, 시작하기 세트 등록 값, 설치 폴더 목록, 오류 내용, `kkl-log.txt`, 로드 보고서, CAD 명령행 기록(LOGFILEMODE를 켜서 `Legacy17\cadlog`에 저장). 도면 내용은 보내지 않습니다.
- **CAD 실행 후 진단** 버튼: AutoCAD 2008/2009를 실행하고 90초 뒤 보고서를 보냅니다. CAD가 뜨면 명령행에 `KKLOAD`를 한 번 입력해 주세요.
- **진단 보내기** 버튼: 지금 상태를 바로 보냅니다.
- 보고서 사본: `%APPDATA%\KkumpleFree\Legacy17\diag`
- 전송 경로: ntfy.sh 중계(약 12시간 보관) → 개발 PC 수신기(`D:\꿈플-2008-로그\receiver.ps1`)가 받아 `D:\꿈플-2008-로그`에 저장.

AutoCAD **2008(R17.1)·2009(R17.2)** 에서 꿈플을 쓰기 위한 시험판입니다. 2010 이상은 기존 `꿈플-설치.exe`를 사용하세요.

## 꼭 알아둘 점

- 꿈플 기능 모듈은 **AutoCAD 2010용(2010–2012 계열)** 으로 만들어진 원본 파일을 그대로 씁니다. 2008/2009용으로 다시 만든 것이 아니므로 **일부 명령은 동작하지 않을 수 있습니다.** (예: PDF 언더레이·투명도 관련 기능은 2010 이후 기능이라 실패 가능성이 큽니다.)
- 실제 AutoCAD 2008/2009에서는 아직 검증하지 않았습니다. 첫 실행 결과(보고서)를 보내주시면 그에 맞춰 고칩니다.
- 필요 환경: Windows용 .NET Framework 4.5 이상(설치기 실행용), AutoCAD 2008/2009 정식판(LT 제외).

## 설치

1. AutoCAD를 **한 번 실행했다가 종료**합니다(사용자 프로필 생성용). 모든 AutoCAD를 닫습니다.
2. `꿈플-2008-2009-연결.exe`를 실행합니다.
3. 목록에서 연결할 AutoCAD를 선택하고 **꿈플 연결(설치)** 을 누릅니다.
4. AutoCAD를 실행합니다. 명령행에 다음과 같은 문구가 나오면 연결된 것입니다.
   `[Kkumple 2008-2009 TEST] Registered N of M commands. Menu: loaded-2009.`
5. 문구가 나오지 않으면 명령행에 `KKLOAD`를 입력합니다.

## 화면에 보이는 것

| 버전 | 리본 | 풀다운 메뉴 '꿈플' | 도구막대(아이콘) |
|---|---|---|---|
| 2009 | 꿈플 I · 꿈플 II 탭 (아래 '리본 탭 표시' 참고) | 표시 | 20개 (숨김 상태로 등록, 우클릭으로 켬) |
| 2008 | **없음** — AutoCAD 2008에는 리본 기능 자체가 없습니다 | 표시 | 20개 |

아이콘은 원본 아이콘을 2008/2009가 읽을 수 있는 BITMAP 형식으로 변환해 넣었습니다(1,288개).

### 리본 탭 표시 (2009)

AutoCAD 2009는 추가 메뉴 파일의 리본 탭을 작업공간에 넣어야 화면에 나타납니다. 탭이 보이지 않으면 한 번만 다음을 하세요.

1. 명령행에 `CUI` 입력 → 사용자 인터페이스 사용자화 창이 열립니다.
2. 왼쪽 위 **작업공간**에서 현재 쓰는 작업공간(예: 2D 제도 및 주석)을 선택하고 오른쪽의 **작업공간 사용자화**를 누릅니다.
3. 왼쪽 목록의 **부분 사용자화 파일 → KKUMPLE → 리본 탭**에서 `꿈플 I`, `꿈플 II`에 체크합니다.
4. **작업 완료** → **확인**.

## 문제 보고

명령행에 `KKREPORT`를 입력하면 메모장으로 보고서가 열립니다. 보고서 파일(`load-report-2008.txt` 또는 `load-report-2009.txt`)과 명령행에 나온 오류 문구를 보내주세요. 보고서에는 등록된 명령 수와 등록되지 않은 명령 목록이 들어 있습니다.

## 제거

1. AutoCAD에서 `KKUNLOADMENU`를 입력해 꿈플 메뉴를 내립니다(다음 실행 때 '메뉴 파일 없음' 경고 방지).
2. AutoCAD를 모두 닫고 연결기에서 **이 컴퓨터에서 제거**를 누릅니다.

제거하면 시작하기 세트에 추가한 꿈플 로더 항목과 `%APPDATA%\KkumpleFree\Legacy17` 폴더만 지웁니다. 도면, `acad.lsp`·`acaddoc.lsp`, 주 CUI, AutoCAD 설치 폴더는 처음부터 변경하지 않습니다.

## 동작 방식 (관리자용)

- 설치 위치: `%APPDATA%\KkumpleFree\Legacy17` (`modules` = 원본 2010 계열 46개 파일, `menus\2008`·`menus\2009` = 변환 CUI + BITMAP 아이콘 DLL, `kkumple-legacy17.lsp` = 로더)
- 자동 로딩: `HKCU\Software\Autodesk\AutoCAD\R17.x\ACAD-xxxx\Profiles\<프로필>\Dialogs\Appload\Startup`(시작하기 세트)에 로더 한 줄 추가
- 로더는 R17.1/R17.2에서만 동작하고, 기존 드림플러스 명령이 이미 있으면 불러오지 않습니다.
- 2009 리본 메뉴가 거부되면 리본 없는 2008용 메뉴로 자동 재시도합니다.
- 빌드: `.\build.ps1 -Body <꿈플.exe>` — 꿈플.exe 안의 2010 계열 압축과 파일 46개의 SHA-256을 원본 목록과 대조합니다.
